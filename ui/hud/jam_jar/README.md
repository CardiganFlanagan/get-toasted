# Банка варенья: HUD для Get Toasted

## Установка

1. Скопируй папку `jam_jar` в проект, например в `res://ui/`.
2. Добавь `jam_jar.tscn` в свой HUD (лучше внутрь CanvasLayer).
3. В коде игрока:

```gdscript
@onready var hp_jar: JamJar = $HUD/HealthJar

func take_damage(amount: float) -> void:
	hp = maxf(hp - amount, 0.0)
	hp_jar.set_value(hp, max_hp)    # урон и лечение банка различает сама

func _physics_process(_delta: float) -> void:
	hp_jar.set_running(velocity.length() > 10.0)   # можно каждый кадр
```

Проверка: запусти `jam_jar_demo.tscn` (F6). Пробел или тап — урон, H — лечение, M — мана, R — бег, 1/2/3 — вкус.

## API

- `set_value(value, max_value)` — новое значение. Урон: тряска, лицо «ай», варенье падает сразу, «призрак» стекает следом. Лечение: плавный подъём со вспышкой.
- `set_running(bool)` — варенье плещется.
- `refill()` — мгновенно полная банка (новый забег).
- `flavor` — вкус: клубника, абрикос, черника. Цвета лежат в `FLAVORS` в `jam_jar.gd`, фрукт на бирке берётся из `jam_jar_tag.png` (кадр = номер вкуса). Новый вкус: строка в `FLAVORS`, имя в `enum Flavor` и новый кадр бирки.
- сигнал `emptied` — банка опустела.

## Слои (холст 48×56, все выровнены по левому верхнему углу)

- `jam_jar_mask.png` — форма банки. Цвет не важен, важна непрозрачность. Контур по краю маски рисует шейдер, поэтому он умеет мигать.
- `jam_jar_tag.png` — бумажная бирка с фруктом, 3 кадра по 48×56: клубника, абрикос, черника. Рисуется под front-слоем, чтобы верёвочка проходила в дырку бирки.
- `jam_jar_front.png` — крышка, бечёвка с верёвочкой к бирке, грани и блики стекла, тень. Грани — полупрозрачные полосы поверх варенья: левая светлее, правая темнее, рёбра светлые.
- `jam_jar_face.png` — лицо, 6 кадров по 48×56: норма, моргание, тревога (брови домиком, дрожащий рот, слеза, пот), тревога с морганием, удар, нокаут.

## Если перерисуешь банку в Aseprite

- Рисуй все слои на одном холсте и экспортируй каждый на весь холст.
- В материале узла `Jam` поправь `fill_top_px` (строка, где поверхность у полной банки, сейчас 16), `fill_bottom_px` (строка под дном, сейчас 51) и `berry_columns_px` (столбцы для ягодок).
- Для круглой банки без граней включи тень у стенки: `shade_width_px = 3`.
- Другой размер холста — поменяй размер у `JamJar`, `Visual`, `Jam` и `Front`.
- Хочешь нарисовать контур сам — выключи `draw_outline` и рисуй его во front.

## Волны

- Передняя волна — параметры `wave_*` в группе motion.
- Задняя волна — группа back_wave: дальняя сторона варенья, темнее и бежит навстречу передней. `back_lightness` — насколько темнее, `back_offset_px` — насколько выше, `draw_back_wave` выключает её совсем.

## Размер

Банка рассчитана на базовое разрешение 640×360. Если нужна крупнее, ставь у корня `scale` целым числом (2, 3), чтобы пиксели не плыли.
